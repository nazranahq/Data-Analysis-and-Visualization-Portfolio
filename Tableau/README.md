# Tableau Projects Portfolio

The projects using **Tableau** form a comprehensive visualization initiative that explores diverse real-world datasets spanning e-commerce, sports, finance, customer behavior, and sustainable transportation.  
The primary objective is to derive actionable insights by transforming raw data into **interactive and informative dashboards**.  
Through hands-on experience with Tableau, five distinct dashboards were created—each addressing a unique domain.

This work involved the end-to-end process of **data connection, calculated field creation, advanced filtering, visual encoding, formatting, and dashboard composition**.  
The outcome is a robust portfolio that showcases the power of data visualization in drawing insights across industries and domains.

## Projects

These projects illustrate proficiency in transforming raw data into actionable insights using Tableau. Explore the individual project links for detailed documentation and visual examples.

- [Amazon Sales Dashboard](./Amazon%20Sales%20Dashboard/README.md): E-commerce sales trends, courier performance, and regional analysis.  
- [Credit Card Complaints Dashboard](./Credit%20Card%20Complaints%20Dashboard/README.md): Financial sector complaint tracking, KPIs, and geospatial insights.  
- [Customer Personality Analysis](./Customer%20Personality%20Analysis/README.md): Marketing segmentation and campaign effectiveness.  
- [Electric Vehicle Population Data Analysis](./Electric%20Vehicle%20Population%20Data%20Analysis/README.md): U.S. EV adoption trends, manufacturer performance, and CAFV eligibility.
- [World Cup Results Dashboard](./World%20Cup%20Results%20Dashboard/README.md): Historic FIFA data with wins, host nations, and audience metrics.  


## Project Structure

Each project folder contains:
- The Tableau workbook (.twb or .twbx)
- Data sources used for analysis
- A PDF document detailing the project, including:
    - Introduction
    - Steps taken
    - Key insights
    - Conclusion

## Lessons Learned
These projects reinforced the importance of **structured data storytelling**.  
They taught how to bridge raw datasets and meaningful narratives using Tableau’s visual analytics capabilities.  
From KPI tracking to temporal trends and geospatial insights, each dashboard revealed different strengths of data visualization in decision-making contexts.

## Skills Gained
- Proficiency in Tableau including calculated fields, parameters, dual-axis charts, filters, and design best practices.  
- Data storytelling through visual metaphors like maps, sparklines, progress bars, and highlight tables.  
- Analytical thinking to frame meaningful questions and derive insights from complex datasets.  
- Domain knowledge across retail, sports analytics, customer service, marketing, and sustainability.

## Future Applications
These dashboards can serve as foundational templates for:
- Executive reporting and performance tracking.

- Business intelligence integration for real-time decision-making.  
- Industry-specific use cases in e-commerce, financial services, sports, marketing, and clean tech.
