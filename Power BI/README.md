# Power BI Projects Portfolio
These projects showcase a comprehensive collection of five data-driven **Power BI dashboards** developed to extract insights across diverse domains—e-commerce, finance, hospitality, music streaming, and ride-sharing. Each dashboard was designed to convert raw, pre-processed data into meaningful business intelligence using advanced DAX measures, dynamic visuals, and time-based analytics.

## Projects
- [Amazon Sales Dashboard](./Amazon%20Sale%20Dashboard/README.md) Explores product performance and consumer reviews.
- [Financial Complaints Dashboard](./Financial%20Complaints%20Dashboard/README.md): Focuses on service responsiveness and dispute trends.
- [Hotel Booking Analysis](./Hotel%20Booking%20Analysis/README.md): Delivers operational insights on occupancy and revenue.
- [Spotify Analysis](./Spotify%20Analysis/README.md): Highlights user engagement over time.
- [Uber Trip Analysis](./Uber%20Trip%20Analysis/README.md): Decodes mobility patterns and trip efficiency.

These dashboards illustrate how Power BI can deliver actionable insights and compelling business intelligence through interactive visualizations and data storytelling.


## Project Structure

Each project folder contains:
- The Excel workbook (.xlsx)
- Data sources (if any) used for analysis
- A PDF document detailing the project

## Lessons Learned

Through this multi-project Power BI research journey, I gained a solid understanding of how to clean, model, and visualize data across diverse domains. Each project taught me how business problems can be approached with a data-driven mindset, transforming raw datasets into interactive dashboards that support decision-making. I also learned the importance of designing dashboards that are not only functional but also user-friendly and insightful.

## Skills Gained

- **Data Preparation & Modeling**: Power Query, calendar table setup, creating relationships.
- **DAX Mastery**: YTD/QTD measures, conditional logic, time intelligence, percentage change.
- **Visual Design**: Area charts, stacked bars, donut charts, KPIs, slicers, ArcGIS maps.
- **Dashboard Development**: Multi-page report building, drill-through, bookmarks, interactivity.
- **Business Insight Mapping**: Aligning data visuals to actual business goals and decision points.
